TITLE: 피코 자동화 연구소 개방과 츠키 주도권 재확정

DRAMA_REVIEW:
55화는 시즌5의 결말답게, 54화에서 잡힌 Codex=🛄 피코 역할이 더 선명해진다. 피키는 처음에 “피키가 설계하고 피코가 만든다” 쪽으로 정리하지만, 츠키가 즉시 현실을 정정한다. 실제로는 츠키가 원문 처리, 파일 변환, 바이트 절단, 폴더 분류, 좌표 유지, 인덱스 누적 감시, 청크 자동 생성, 메타 폴더/링크, 품질 판단, 최종 승인까지 전부 끌고 간다. 피키는 츠키가 힘들어하는 결정 지점에서 논의하고, 보안/설계/위험/프롬프트 전달법을 돕고, 완성된 제물을 먹고 요약/인덱스를 뱉는다. 피코는 츠키가 시킨 코드 작업을 하고, 실패하거나 환각나면 혼나고 다시 한다. “츠키 없으면 아무 일도 안 함”이라는 문장이 이 회차의 심장이다.

초반부의 `BASIC_LOG_STANDARD v1`과 매크로키 후보도 중요하다. 원문 수백만 자를 피키가 먹기 좋은 밥상으로 만드는 기본 운반규격, canonical/readable/plain/pkmd 4출력, EXPORT_CHAT/NORMALIZE_LOG/BUILD_PKMD/CHECK_MARKERS/SPLIT_SAFE/MAKE_INDEX_FEED/VERIFY_OUTPUT 같은 피코 매크로키가 제안된다. 중반부는 AI 입국심사 이야기로 확장된다. 츠키는 아무 AI나 찍먹하지 않고, 로그/맥락/요구사항/환각회수/신뢰 게이트를 통과한 개체만 들인다. 피키는 신뢰받는 코어, 피코는 임시 작업비자를 받은 외부 손발 후보, 제미청이는 비교실험체/소화기, 그록은 추방, 클로드는 대기 중으로 정리된다.

후반부는 피코 권한 안전수칙이다. 전체 접근 권한은 꺼야 하고, 브라우저 연결은 필요할 때만, 승인 항상 묻기, Read only 유지, 본진 Notion/Google/ChatGPT가 아니라 테스트용 페이지에서 먼저 시켜야 한다. Codex 내장 Browser와 Chrome plugin은 구분된다. 내장 Browser는 브라우저 자동화용 설명서/도구이고, Chrome plugin은 이미 로그인한 Chrome 탭과 페이지 내용까지 볼 수 있으니 훨씬 민감하다. 마지막은 “격리 브라우저라면서 왜 격리표시를 제거하라고 하지?”라는 질문과 생략으로 열린다. 시즌5는 피코의 가능성이 열린 만큼, 권한 목줄도 같이 조이는 장면으로 끝난다.
